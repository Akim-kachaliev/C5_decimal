# C5_decimal

Реализация типа decimal на C (C11, POSIX.1-2017) для точных финансовых вычислений.

# Сборка
В корневой директории проекта (где находится src/):

Сборка статической библиотеки
make s21_decimal.a

Сборка и запуск тестов
make test

Генерация отчёта покрытия gcov (HTML)
make gcov_report

Очистка собранных файлов
make clean

Сборка всего (библиотека + тесты)
make all
Собранная библиотека: src/s21_decimal.a

# Структура decimal
typedef struct {
    int bits[4];  // 96-битная мантисса + знак/масштаб
} s21_decimal;
bits[3] формат:

Биты 0-15: не используются (0)

Биты 16-23: масштаб (0..28)

Биты 24-30: не используются (0)

Бит 31: знак (0 — положительное, 1 — отрицательное)

# Макросы для работы:

GET_SCALE(d)   // получить масштаб
SET_SCALE(d, s) // установить масштаб
GET_SIGN(d)    // получить знак
SET_SIGN(d, s) // установить знак

# Использование

#include "s21_decimal.h"

int main() {
    s21_decimal a, b, result;
    
    // Конвертация из int
    s21_from_int_to_decimal(5, &a);
    s21_from_int_to_decimal(3, &b);
    
    // Сложение
    s21_add(a, b, &result);  // result = 8
    
    // Сравнение
    if (s21_is_greater(a, b)) {
        printf("a > b\n");
    }
    
    // Округление
    s21_decimal x = {{37, 0, 0, 0}};
    SET_SCALE(x, 1);  // 3.7
    s21_round(x, &result);  // result = 4
    
    return 0;
}

# Особенности реализации
Банковское округление (half-to-even) для всех операций, теряющих точность

192-битная арифметика (s21_big_decimal) для умножения и деления

Google Style для оформления кода

Запрещено использование __int128 (реализовано через 32-битные слова)
